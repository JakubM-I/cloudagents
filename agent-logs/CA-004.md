# CA-004 — JSON task schema with HTML presentation page

## Summary
Created a simple JSON Schema describing task details (task ID, name, short description, status, completed steps, tools used) and a static HTML page presenting it: header, a panel with the schema, and a field description table below. Everything lives in `josn-claude-template/`.

## Actions
- Synchronized with `origin/main` and read `AGENTS.md` and `.claude/WORKFLOW.md`.
- Added `josn-claude-template/task-schema.json` (JSON Schema draft 2020-12).
- Added `josn-claude-template/index.html` with the header, schema panel and fields table.
- Added `josn-claude-template/styles.css` (plain CSS, light/dark via `prefers-color-scheme`, responsive table on narrow screens).

## Decisions
- Plain HTML + CSS, no JavaScript: the schema is embedded in the page as escaped text, so the page also works when opened from `file://` (where `fetch()` of a local JSON file is blocked).
- Field names in English snake_case (`task_id`, `name`, `description`, `status`, `steps_completed`, `tools_used`) following the repository language rule.
- `status` enum mirrors the statuses used in the repository workflow (`todo`, `in_progress`, `completed`, `partial`, `blocked`).
- `task_id` is constrained to the repository format `CA-<number>`; `additionalProperties: false` keeps the format strict.
- Steps and tools are plain string arrays to keep the schema simple.

## Problems encountered
- Task ID `CA-003` is already used by an unmerged branch (`claude/intelligent-clarke-iuicds`), so this task uses `CA-004` to keep IDs unique.

## Assumptions
- The directory name `josn-claude-template` (with the "josn" spelling) is intentional, matching the requested path and the existing `josn-template/`.
- Page content in English per `AGENTS.md`, although the request was written in Polish.

## Validation
- Parsed `task-schema.json` with Python `json`.
- Checked the schema with `jsonschema.Draft202012Validator.check_schema`; a valid sample produced no errors and an invalid sample (bad status, extra property) was rejected as expected.
- Rendered the page in headless Chromium (Playwright) at 1280px and 390px widths and inspected screenshots; no horizontal page scroll (`scrollWidth` equals viewport width).
- The schema text in `index.html` was generated from `task-schema.json`, so they match at commit time.
- Not performed: HTML validator (W3C) check, cross-browser testing beyond Chromium.
