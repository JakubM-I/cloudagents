Jak czytać ten plik

Element po elemencie

linia 2

properties

Obiekt grupujący pola, które może zawierać opisywane zadanie.

linie 3–8

task_id

Jednoznaczny identyfikator zadania. Wzorzec ^CA-[0-9]+$ dopuszcza wartości takie jak CA-004.

linie 9–16

name

Krótka nazwa widoczna dla człowieka. minLength: 1 oznacza, że nie może być pusta.

linie 17–23

description

Zwięzłe wyjaśnienie celu lub zakresu zadania. Przykład pokazuje, jak może wyglądać prawidłowa treść.

✦ Wskazówka: type określa rodzaj danych, a examples pokazuje przykładową poprawną wartość.
