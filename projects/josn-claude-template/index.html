Data format

Task JSON Schema

A simple JSON format for describing a single task: its identity, status, completed steps and the tools used.

task-schema.json

JSON Schema 2020-12 
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "task-schema.json",
  "title": "Task details",
  "description": "Describes a single task: what it is, where it stands, what was done and which tools were used.",
  "type": "object",
  "required": ["task_id", "name", "description", "status", "steps_completed", "tools_used"],
  "properties": {
    "task_id": {
      "type": "string",
      "description": "Unique task identifier in the format CA-<number>.",
      "pattern": "^CA-[0-9]+$",
      "examples": ["CA-004"]
    },
    "name": {
      "type": "string",
      "description": "Short, human-readable task name.",
      "minLength": 1,
      "examples": ["Create a JSON task template"]
    },
    "description": {
      "type": "string",
      "description": "Brief summary of the task goal or scope.",
      "examples": ["Define a JSON schema for task details and present it on a static HTML page."]
    },
    "status": {
      "type": "string",
      "description": "Current task status.",
      "enum": ["todo", "in_progress", "completed", "partial", "blocked"]
    },
    "steps_completed": {
      "type": "array",
      "description": "Ordered list of steps already performed.",
      "items": { "type": "string", "minLength": 1 },
      "examples": [["Synchronized with origin/main", "Created task-schema.json"]]
    },
    "tools_used": {
      "type": "array",
      "description": "Tools used while working on the task.",
      "items": { "type": "string", "minLength": 1 },
      "uniqueItems": true,
      "examples": [["git", "Bash", "Python"]]
    }
  },
  "additionalProperties": false
}

Fields

FieldTypeDescription
task_idstringUnique task identifier in the format CA-<number>, e.g. CA-004.
namestringShort, human-readable task name. Must not be empty.
descriptionstringBrief summary of the task goal or scope.
statusstring (enum)One of todo, in_progress, completed, partial, blocked.
steps_completedarray of stringsOrdered list of steps already performed.
tools_usedarray of stringsTools used while working on the task. Each tool is listed once.

All fields are required. Properties not listed above are rejected (additionalProperties: false).
