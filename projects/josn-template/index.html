Schemat JSON zadania

Prosty format do opisywania postępu i szczegółów pojedynczego zadania.

Plik task-schema.json

JSON Schema 
{
  "id_zadania": "ZAD-001",
  "nazwa_zadania": "Przygotowanie raportu",
  "krotki_opis": "Przygotowanie miesięcznego zestawienia wyników.",
  "status": "w_trakcie",
  "wykonane_kroki": [
    "Zebrano dane",
    "Utworzono wstępną wersję raportu"
  ],
  "zastosowane_narzedzia": [
    "Arkusz kalkulacyjny",
    "Edytor tekstu"
  ]
}

Opis pól

id_zadania

Unikalny identyfikator zadania, np. ZAD-001.

nazwa_zadania

Krótka i zrozumiała nazwa zadania.

krotki_opis

Zwięzły opis celu lub zakresu prac.

status

Jeden z etapów: nowe, w_trakcie, zrealizowane lub zablokowane.

wykonane_kroki

Tablica z listą działań już wykonanych.

zastosowane_narzedzia

Tablica zawierająca nazwy użytych narzędzi.
