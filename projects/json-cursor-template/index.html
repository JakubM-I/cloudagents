Task JSON Schema

A simple format for describing one task: its identifier, name, short description, status, completed steps, and the tools that were used.

Field descriptions

task_id
Unique task identifier in the format CA-<number>, for example CA-005.
name
Short, human-readable task name. Must not be empty.
description
Brief summary of the task goal or scope.
status
Current status. One of todo, in_progress, completed, partial, or blocked.
steps_completed
Ordered list of steps already performed. Each item is a non-empty string.
tools_used
Tools used while working on the task. Each tool is listed once.

All six fields are required. Extra properties are rejected.
