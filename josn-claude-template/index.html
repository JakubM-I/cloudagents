Task JSON Schema

A simple JSON format for describing a task: its identity, status, completed steps and the tools used.

task-schema.json

{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "task-schema.json",
  "title": "Task details",
  "description": "Describes a single task: what it is, where it stands, what was done and which tools were used.",
  "type": "object",
  "required": ["id", "name", "description", "status", "steps", "tools"],
  "properties": {
    "id": {
      "type": "string",
      "description": "Unique task identifier.",
      "pattern": "^CA-[0-9]+$",
      "examples": ["CA-003"]
    },
    "name": {
      "type": "string",
      "description": "Short, human-readable task name.",
      "minLength": 1,
      "examples": ["JSON task template page"]
    },
    "description": {
      "type": "string",
      "description": "One or two sentences explaining the goal of the task.",
      "examples": ["Create a JSON schema for task details and a static page that presents it."]
    },
    "status": {
      "type": "string",
      "description": "Current stage of the task.",
      "enum": ["todo", "in_progress", "completed", "partial", "blocked"]
    },
    "steps": {
      "type": "array",
      "description": "Ordered list of steps that have been completed.",
      "items": { "type": "string", "minLength": 1 }
    },
    "tools": {
      "type": "array",
      "description": "Tools, languages or services used to carry out the task.",
      "items": { "type": "string", "minLength": 1 },
      "uniqueItems": true
    }
  },
  "additionalProperties": false
}
{
  "id": "CA-003",
  "name": "JSON task template page",
  "description": "Create a JSON schema for task details and a static page that presents it.",
  "status": "completed",
  "steps": [
    "Defined the task schema",
    "Wrote an example task",
    "Built the presentation page"
  ],
  "tools": ["HTML", "CSS", "JavaScript", "Git"]
}

Fields

All fields are required. No other fields are allowed.

id string
Unique task identifier in the format CA-<number>, e.g. CA-003.
name string
Short, human-readable task name. Cannot be empty.
description string
Brief description of the task goal, one or two sentences.
status enum
Current stage of the task. One of: todo in_progress completed partial blocked
steps string[]
Ordered list of completed steps. May be empty for a task that has not started.
tools string[]
Tools, languages or services used in the task. Each entry must be unique.
